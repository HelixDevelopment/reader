== IMPORTANT
I1. Truncated log false green in --check mode (A5): a log ending mid-package with no `ok|FAIL <pkg>`
    terminator (e.g. SIGKILL/OOM of the test binary) -> "GATE GREEN" rc=0. In live mode the go test RC
    catches this (exit 1), but --check is documented as "0 only when none apply". Buffered records left at
    END with no terminator (and no `# PKG` marker context) should be NO-RESULTS/INCOMPLETE.
I2. docs/live-gated-tests.md says phase B "runs every test that skipped in phase A" and that the `# PKG`
    marker gives the package identity; at this head both are false (B1, B2). Docs must match behaviour.
I3. Hidden dependency on grep -P (run_gated_tests.sh: `grep -vP '^(PASS|SKIP|SEEN)\t'`). Where grep lacks
    PCRE the process substitution is empty and every FAIL/BUILDFAIL/PANIC/TIMEOUT record is ignored -> false
    green. Use awk -F'\t' '$1!="PASS"&&$1!="SKIP"&&$1!="SEEN"' instead. (Host grep has -P; the fail-open is
    UNCONFIRMED on any other host.)
I4. Missing --allow file is not a setup error: prints "No such file or directory" and continues (A12, rc=3
    here only because a skip existed). With zero net skips a missing allow-list would be GATE GREEN; it should
    exit 2.
