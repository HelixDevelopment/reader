# Client screenshots and videos (HRD-076)

Real captures of every client that could be driven, taken only inside the isolated rootless container runner (`tools/isolation/`,
policy in [`test-isolation.md`](test-isolation.md)): private Xvfb or headless browser inside the container, `--network none`, only a unix-socket
bridge to a throwaway server, no host DISPLAY/WAYLAND/X sockets, no host clipboard or apps. Nothing here is a mock-up.

| Client | Evidence directory | Manual |
|---|---|---|
| Web | [`evidence/screenshots/web/`](../evidence/screenshots/web/) (21 PNG, 1 webm) | [web](manuals/web_client_manual.md) |
| Linux desktop (Electron) | [`evidence/screenshots/desktop/`](../evidence/screenshots/desktop/) (6 PNG, 1 step video) | [desktop](manuals/desktop_client_manual.md) |
| KOReader | [`evidence/screenshots/koreader/`](../evidence/screenshots/koreader/) (13 PNG, KOSync proof) | [koreader](manuals/koreader_manual.md) |
| Android | [`evidence/screenshots/android/`](../evidence/screenshots/android/) (manifest referencing earlier HRD-022 captures) | [android](manuals/android_client_manual.md) |

Each directory holds `capture_manifest.json` (client, version, scenario, resolution, sha256, producing command per image),
`container_proof.json` (the runner's isolation proof) and `SHA256SUMS` (written by `tools/isolation/seal_evidence.sh`).
Also: [quick start](quickstart.md), [tutorial: first library tour](tutorials/first_library_tour.md),
[tutorial: KOReader OPDS and sync](tutorials/koreader_opds_and_sync.md), [FAQ](faq.md).

## Reproduce

```
qa/isolation/run_capture_web.sh      <out-dir>
qa/isolation/run_capture_desktop.sh  <out-dir>
qa/isolation/run_koreader_gui.sh     <out-dir>
python3 qa/isolation/make_capture_manifest.py ...   # host side, writes capture_manifest.json
tools/isolation/seal_evidence.sh <out-dir>
```

The library shown is generated by `qa/isolation/make_capture_fixtures.py` (27 works, no cover art).

## Tooling fix made for this task

The runner's bind checker refused the unix-socket bridge directory because it contains a socket. `tools/isolation/bindcheck.py` now accepts
exactly the one real socket `h.sock` in the bridge directory and still refuses any other socket or the same directory without the bridge flag
(test `test_bridge_dir_may_hold_its_one_real_unix_socket_only`; RED/GREEN logs in `evidence/screenshots/tooling/`).

## UNCONFIRMED

- **Android was not re-captured.** The sanctioned emulator driver (`run_android_emulator.sh`) is not on `main` and the available path depends on a
  host adb; the tracked HRD-022 images are referenced, not new captures.
- No KOReader video; the desktop video is a **step video** (one real frame per step, 1 fps), not a continuous recording.
- Only Chromium was used for the web captures; Firefox and WebKit were not captured.
- The desktop capture used the packaged 0.1.0 build; it was not rebuilt by this task. The Connection dialog was not captured.
- The fixture library has no cover art; the KOReader CBZ pages are solid colours.
- Windows, macOS and iOS clients are not captured.
- Pre-existing, not caused by this task: `tools/isolation/tests/test_review_round3.py::test_every_runner_passes_a_host_only_proof_path` fails on `run_uiverify.sh` (`$W/host-proof` instead of `$HW/`).
