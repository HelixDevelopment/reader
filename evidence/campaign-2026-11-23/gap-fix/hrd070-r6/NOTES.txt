EXACT SCOPE (what "every rule" means here)
- Scope is DERIVED from execution, not hand-listed: covered_functions.txt is produced by `enumerate_rules.py covered`, which runs
  the seed run of the six fuzz targets' packages with a coverage profile and lists every production function with a covered
  statement (48 branch-bearing functions, 200 branches). `check` fails if any branch of any such function has no rule row, if a
  row is stale, if a row's own-line mutant has the wrong outcome, or if no mutant edits a line inside the row.
- NOT covered (named, not hidden): other packages (e.g. catalog), functions the seed run does not execute, and the HTTP handler
  layer server/internal/httpapi/kosync.go (body limits, ShouldBindJSON, status mapping 400/401/402/500). The handler layer is a
  TRACKED FOLLOW-UP (review item M2), not fuzzed here. UNCONFIRMED: that its limits/status mapping behave as intended under
  adversarial input.
